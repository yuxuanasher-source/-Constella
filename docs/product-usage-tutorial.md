# 经营舱用户使用教程

适用对象：MCN 负责人、运营负责人、一线运营、财务、主播

本教程面向经营舱的日常使用者。它不介绍技术部署和开发细节，只说明登录后怎么完成业务动作：创建项目、邀约主播、排班直播、提交报数、审核结算、导出交付和查看复盘。

## 1. 认识经营舱

经营舱是一套面向游戏直播 MCN / 直播工作室的项目经营系统。它把原本分散在表格、群聊和人工对账里的工作，收拢到一条完整链路里：

```text
创建项目
  → 邀约或筛选主播
  → 审核录屏并确认入项
  → 创建直播任务
  → 主播开播、下播、上传截图并报数
  → 运营审核报数
  → 生成结算批次
  → 财务核对、锁定、导出
  → 审计、通知、复盘和下次经营建议
```

你只需要记住一句话：项目是主线，主播、任务、报数、结算和复盘都围绕项目展开。

## 2. 登录和入口

### 经营团队入口

负责人、运营负责人、一线运营和财务登录后会进入经营后台。经营后台用于管理项目、主播、任务、审核、结算、导出、通知和复盘。

首次使用时：

1. 打开管理员提供的登录地址。
2. 输入邮箱或手机号和密码。
3. 如果是机构首次开通，按页面提示注册机构账号。
4. 如果是管理员创建的子账号，按页面提示激活账号并设置新密码。
5. 登录后确认自己看到的菜单是否和岗位一致。

### 主播入口

主播登录后会进入主播端。主播端有移动端和桌面端两种使用方式：

| 入口       | 适合场景               | 主要功能                                         |
| ---------- | ---------------------- | ------------------------------------------------ |
| 主播移动端 | 手机查看任务、临场操作 | 今日任务、开播下播、上传截图、提交报数、查看收益 |
| 主播桌面端 | 桌面直播工作流         | 工作台、录屏库、AI 复盘、结算账单、个人档案      |

主播只会看到自己的任务、报数、录屏和结算信息，不会看到其他主播或机构内部财务数据。

## 3. 角色能做什么

| 角色       | 主要职责                 | 常用功能                                                       |
| ---------- | ------------------------ | -------------------------------------------------------------- |
| 负责人     | 管理机构经营和高风险动作 | 发布项目、确认主播入项、锁定/重开结算、查看审计和高风险提醒    |
| 运营负责人 | 负责项目执行             | 发布项目、邀约主播、排班、审核报数、生成结算、导出交付         |
| 一线运营   | 维护日常执行             | 创建项目草稿、维护主播、处理录屏和报数、创建任务               |
| 财务       | 核对结算和导出财务数据   | 查看结算批次、核对金额、导出授权数据                           |
| 主播       | 完成直播任务并提交证据   | 查看任务、开播下播、上传截图、提交报数、提交录屏、查看个人结算 |

如果你看不到某个按钮，通常是因为当前角色没有权限，或者当前业务状态还没有到这一步。

## 4. 经营团队：完成一个项目

### 第一步：创建项目草稿

1. 进入“项目管理”。
2. 点击“新建项目”。
3. 填写项目名称、项目编号、厂商/产品、起止时间、负责人和结算方式。
4. 根据项目要求选择是否强制录屏、是否要求主播点击开播/停止。
5. 点击“创建草稿”。

创建后，项目会先进入草稿状态。草稿可以继续补充信息，也可以由有权限的人发布招募。

### 第二步：发布项目招募

1. 在项目列表中打开项目详情。
2. 检查项目基础信息、准入规则、结算规则和负责人。
3. 点击“发布招募”。
4. 发布后，项目进入招募中，主播可以报名，运营也可以定向邀约主播。

注意：一线运营可以创建项目草稿，但通常不能发布招募。发布项目需要负责人或运营负责人权限。

### 第三步：维护主播档案

1. 进入“主播池”。
2. 点击“创建档案”。
3. 填写主播名称、平台账号、品类能力、供应商、风险状态和默认结算规则。
4. 保存后，在主播列表中确认档案是否出现。

如果主播暂时没有登录账号，可以先建立档案，后续再绑定账号。被标记为黑名单或受限的主播，不能正常报名、邀约或排班。

### 第四步：邀约主播和审核录屏

1. 打开项目详情，进入“主播阵容”。
2. 点击“邀请主播”，选择要邀约的主播。
3. 主播确认后，按项目要求提交试播或报名录屏。
4. 运营在“选播准入”中查看待审录屏。
5. 根据录屏质量选择“通过”“驳回”或“要求补充”。
6. 录屏通过后，由负责人或运营负责人进行二次确认。

只有二次确认后，主播才算正式加入项目。录屏通过本身不等于已入项。

### 第五步：创建直播任务

1. 进入“排班直播”。
2. 点击“新建任务”，选择项目、主播、计划开播时间和计划结束时间。
3. 如果要一次安排多个主播，使用“批量排班”。
4. 创建后检查任务列表，确认项目、主播、时间和状态正确。

系统只允许给已正式加入项目的主播排班。未入项主播不能直接进入直播任务。

### 第六步：处理异常和待办

任务执行过程中，系统会把未开播、未报数、报数逾期、缺少截图、长时间未停止等情况放入异常或待办提醒。

运营应定期检查：

1. “通知待办”里的未处理事项。
2. “排班直播”里的异常任务。
3. 项目详情中的待审核录屏、待上传报数和待处理异常。

优先处理会影响结算或交付的异常。

## 5. 主播：完成一场直播

### 第一步：查看今日任务

1. 登录主播端。
2. 进入“我的任务”。
3. 查看项目名称、开播时间、预计时长、结算提示和录屏要求。
4. 如果任务要求录屏或点击开播/停止，请提前确认直播工具和录屏链接准备好。

如果看不到任务，请联系运营确认是否已经正式加入项目，以及排班是否已创建。

### 第二步：开播和下播

1. 到达计划时间后，点击“开始直播”。
2. 直播结束后，点击“停止直播”。
3. 按页面提示上传下播截图。

对于要求系统计时的项目，请务必点击开始和停止。系统会用这段时间作为重要结算证据。

### 第三步：提交报数

1. 在任务详情里点击“上传截图”或“提交报数”。
2. 上传下播截图。
3. 核对系统识别出的时长、场观等数据。
4. 如果识别不准确，可以按实际情况修改，并填写说明。
5. 提交后等待运营审核。

报数提交后通常会进入“审核中”。如果被驳回或要求补充，请按通知重新提交。

### 第四步：提交录屏链接

如果项目要求试播、报名录屏或历史录屏：

1. 进入“录屏库”。
2. 点击“提交录屏链接”。
3. 填写产品/游戏、品类、归档月份和可访问的录屏 URL。
4. 提交后关注审核状态。

录屏链接应确保运营可打开。如果链接需要私有登录、过期或内容不匹配，可能会被驳回。

### 第五步：查看收益和申请复核

1. 进入“我的”或“结算账单”。
2. 查看本月收益、已锁定批次和每条结算明细。
3. 如果对金额有疑问，点击“申请复核”。
4. 补充说明后等待运营或财务处理。

主播端只展示个人应付信息。厂家应收、MCN 毛利、内部成本、其他主播结算等信息不会显示。

### 第六步：使用 AI 诊断

1. 进入“AI 诊断”或桌面端 AI 复盘区。
2. 描述遇到的问题，例如“最近直播转化变差”。
3. 按 AI 提问补充关键信息。
4. 查看卡点判断、证据、改进建议和下次实验方向。

AI 只会基于你自己的任务、报数和录屏数据给建议。

## 6. 运营：审核报数

主播提交报数后，运营需要在“报数审核”中处理。

1. 打开“报数审核”。
2. 查看待审核报数列表。
3. 对比系统计时、截图识别结果和主播确认值。
4. 判断证据等级：
   - 绿色：系统计时和截图基本一致，可以优先通过。
   - 黄色：缺少部分系统证据，需要人工确认。
   - 红色：主要依赖主播填报，需要填写审核原因。
5. 根据情况选择“审核通过”“驳回”或“要求补充”。

审核通过后，报数会进入可结算池，但不会自动生成结算批次。结算仍需运营或财务按周期处理。

## 7. 财务：核对结算

财务主要负责核对金额和导出数据。

1. 进入“结算中心”。
2. 查看可结算池，确认本期可结算报数。
3. 查看已生成的结算批次。
4. 区分两类金额：
   - 系统核验金额：如 CPT、底薪、底薪 + CPT。
   - 人工承载金额：如 CPA、CPS、礼物流水、补贴、扣减和调整项。
5. 核对无误后，由有权限的人确认并锁定批次。
6. 使用“导出”生成授权范围内的结算表。

财务可以核对和导出，但通常不能创建项目、审核报数、修改结算规则或重开锁定批次。

## 8. 负责人：处理高风险动作

以下操作属于高风险动作，通常需要负责人关注：

| 动作               | 为什么重要               |
| ------------------ | ------------------------ |
| 修改项目结算规则   | 会影响后续结算口径       |
| 修改主播风险状态   | 会影响报名、邀约和排班   |
| 修改主播报数值     | 会影响结算金额           |
| 锁定或重开结算批次 | 会影响财务确认和主播收益 |
| 导出敏感财务数据   | 涉及数据安全和外部交付   |

执行高风险动作时，系统会要求填写原因，并记录审计日志。负责人应在“通知待办”和“审计中心”中查看相关提醒。

## 9. 导出和交付

“导出交付”用于生成项目、主播、报数、结算和厂家交付相关数据。

使用时注意：

1. 只导出当前角色有权限查看的数据。
2. 对外交付的数据会隐藏敏感字段。
3. 财务导出和敏感数据导出会记录审计。
4. 导出完成后，在通知或导出列表中查看结果。

如果发现导出内容缺少字段，先确认当前账号是否有权限查看该字段。

## 10. 作战台和复盘

“智能作战台”用于经营决策，不用于直接替代人工审批。

常见用途：

1. 立项前做报价测算。
2. 招募时做主播匹配。
3. 执行中查看异常和待审核压力。
4. 结项后生成项目复盘。
5. 基于历史数据给出下次选播、定价和供应商建议。

作战台输出的是建议。涉及发布项目、确认主播、修改金额、锁定结算等生产动作，仍需要有权限的人手动确认。

## 11. 常见问题

**我登录后看不到某个菜单**

请先确认账号角色。不同角色看到的菜单不同。财务、主播和一线运营都会受到权限限制。

**我无法发布项目**

发布项目通常需要负责人或运营负责人权限，并且项目必须处于可发布状态。

**主播看不到任务**

请确认主播已经正式加入项目，并且运营已经为该主播创建排班。

**任务完成后不能报数**

请确认任务没有被取消，且已经到达可报数状态。若项目要求点击开始/停止，请确认直播前后是否完成操作。

**报数审核通过后为什么还没有结算金额**

审核通过只代表报数进入可结算池。结算金额需要在“结算中心”按周期生成结算批次后才会出现。

**结算批次锁定后发现错误怎么办**

请联系负责人。锁定批次需要由有权限的人填写原因后重开，再重新核对和锁定。

**主播为什么看不到厂家应收或毛利**

这是系统的数据安全设计。主播端只展示个人应付和与本人相关的安全明细。

**导出数据缺字段**

导出结果会根据当前账号权限和数据敏感级别过滤。对外交付包不会包含内部成本、毛利、风险备注等敏感信息。

## 12. 日常使用建议

1. 项目开始前，先确认项目规则、录屏要求和结算方式。
2. 主播入项前，一定完成录屏审核和二次确认。
3. 排班后，提醒主播按要求点击开播和停止。
4. 每天检查待审核报数和异常任务。
5. 每个结算周期结束后，先核对可结算池，再生成批次。
6. 高风险操作必须写清楚原因，方便后续追溯。
7. 对外导出前，确认数据范围和脱敏要求。
