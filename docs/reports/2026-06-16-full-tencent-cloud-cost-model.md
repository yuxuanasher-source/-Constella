# 全量腾讯云成本测算

日期：2026-06-16

## 1. 结论

如果现有方案全量切到腾讯云，第一版按“广州地域 + 腾讯云基础设施 + 腾讯 OCR + 腾讯 COS + 腾讯云 PostgreSQL/自建 Auth 替代 + 腾讯云日志监控 + 腾讯云 CDN/网络”测算。

核心结论：

| 项目                                   |                                             测算结果 |
| -------------------------------------- | ---------------------------------------------------: |
| 基准客户结构                           | 入门 40、基础 60、专业 25、经营 8、企业 2，共 135 户 |
| 基准月含税收入                         |                                         203187.84 元 |
| 基准月不含税收入                       |                                         191686.64 元 |
| 基准月腾讯云资源成本                   |                                          56172.29 元 |
| 基准月腾讯云资源成本率                 |                                                27.6% |
| 基准月 OCR 压力资源成本                |                                          64932.29 元 |
| 基准月直接成本，含支付和支持，可选参考 |                                          72544.61 元 |
| 基准月直接贡献                         |                                         119142.03 元 |

按当前套餐设计，并按“录屏只保存链接、不保存视频文件”修正后，全量腾讯云资源成本率约 28%。腾讯云账单里的主要变量不是 CVM 本身，而是 OCR、主播端用量、COS 截图/导出存储、网络下载和 AI 调用。

与原来误按“录屏视频也进入 COS/下载链路”的口径相比，基准情景每月腾讯云资源成本从 60045.89 元降到 56172.29 元，减少 3873.60 元。如果只修正存储、不修正下载，减少约 513.60 元；如果录屏播放/下载完全不走腾讯云链路，降幅可能接近 5217.60 元/月。

## 2. 全量腾讯云目标架构

| 层        | 腾讯云方案                                              | 成本进入项               |
| --------- | ------------------------------------------------------- | ------------------------ |
| Web/API   | CVM 或 TKE 跑 Next.js，也可部分云函数化                 | App/Serverless           |
| Auth      | 替代 Supabase Auth，自建账号服务，接短信/邮件/OAuth     | App、DB、短信、邮件      |
| 数据库    | 云数据库 PostgreSQL，保留 RLS、函数、触发器、视图       | DB/缓存                  |
| 私有文件  | COS 私有 bucket，存报数截图、导出包；录屏只保存外部链接 | 存储、请求、下载、回源   |
| OCR       | 腾讯云 OCR `GeneralBasicOCR`                            | OCR 按次、资源包、QPS 包 |
| AI        | 腾讯混元/TokenHub，或保留 OpenAI 时单独列外部成本       | AI 调用                  |
| Worker    | OCR runner、导出、异常扫描、自动审核                    | Worker/队列              |
| 缓存/队列 | 早期可 DB 队列表，规模后 Redis/TDMQ                     | DB/缓存、Worker/队列     |
| 日志监控  | CLS、云监控、告警                                       | 监控/日志                |
| 网络下载  | CDN/EdgeOne、CLB、公网流量                              | 网络/下载                |
| 支付      | 微信/支付宝/聚合支付                                    | 支付手续费，不算云资源   |

说明：本表是“云资源月成本”测算，不包含 Supabase 替代的一次性迁移开发成本。Auth、Storage、PostgREST/RLS 兼容、回归测试和数据迁移需要另立项目成本。

## 3. 计价假设

| 项目               |                                      基准假设 |
| ------------------ | --------------------------------------------: |
| 收入口径           |                  不含税收入 = 含税收入 / 1.06 |
| 支付手续费         |                             含税交易额 × 0.7% |
| OCR 基准成本       |                                  0.10 元 / 次 |
| OCR 压力成本       |                                  0.15 元 / 次 |
| AI 基准成本        |                             0.05 元 / AI call |
| 存储成本           | 0.15 元 / GB / 月，含容量、请求和少量下载冗余 |
| 非录屏文件实际占用 |                                套餐额度的 20% |
| OCR 月额度         |                    活跃主播席位 × 30 天 × 80% |
| 主播端用量收入     |   按套餐订阅收入的 8% / 12% / 18% / 22% / 25% |
| 主播端用量成本     |                          主播端用量收入的 35% |

公开价校准：

- 腾讯云 OCR 通用印刷体识别后付费公开阶梯为 0.15 / 0.10 / 0.06 元每次，按月调用量分档。
- 腾讯云 COS 标准存储示例价格为 0.118 元/GB/月，标准存储请求示例为 0.01 元/万次，外网下行示例为 0.5 元/GB。
- 腾讯云 CDN 中国大陆 0-2TB 流量阶梯示例为 0.21 元/GB。
- 腾讯云 CLS 常用示例为日志写流量 0.18 元/GB、标准索引流量 0.35 元/GB、标准日志/索引存储 0.0115 元/GB/日。
- 腾讯云 PostgreSQL 公开文档给出计费公式：规格费用 + 存储空间费用 + 超额备份空间费用等，具体规格价格需要用控制台价格计算器确认。

## 7. 敏感性

| 风险变量                | 影响                                                                     |
| ----------------------- | ------------------------------------------------------------------------ |
| OCR 单价从 0.10 到 0.15 | 基准情景腾讯云资源成本从 56172.29 增至 64932.29，每月增加 8760.00        |
| AI 全额度打满           | 基准情景每月约增加 2317.50，低于 OCR 压力影响                            |
| 未来改为自托管录屏      | COS 容量和下载流量会回到原视频托管口径，基准情景至少增加约 3873.60 元/月 |
| 厂家频繁下载交付包      | CDN/COS 外网下行可能超过当前网络/下载假设                                |
| Shadow AI 常开          | AI 成本近似翻倍，应只对抽样流量开启                                      |
| OCR 重试无上限          | 直接放大 OCR 成本，应设置重试上限和人工回退                              |

## 8. 预算建议

1. 冷启动生产环境先按 4500-6000 元/月预留腾讯云资源预算。
2. 100 户基准运营按 5.3 万元/月腾讯云资源成本管理，OCR 压力场景预留到约 6.2 万元/月。
3. 135 户基准商业情景按 5.6 万元/月腾讯云资源成本、7.3 万元/月直接成本管理。
4. 如果 OCR 单价只能拿到 0.15 元/次，135 户基准情景需要额外预留约 8760 元/月。
5. 企业版报价不能承诺无限 OCR、无限 AI、无限存储；企业客户必须签 quota override 或 recurring add-on。
6. 全量腾讯云迁移的一次性工作不应混入月云成本，建议单独估 2-4 周工程成本：Auth 替换、Storage 替换、RLS/接口回归、数据迁移、上线演练。

## 9. 采购前必须确认

| 项目        | 确认动作                                                     |
| ----------- | ------------------------------------------------------------ |
| CVM/TKE     | 用腾讯云价格计算器按广州地域确认 Web/API/Worker 规格         |
| PostgreSQL  | 确认实例规格、存储、备份、只读实例和审计费用                 |
| COS         | 购买容量包、请求包、下行流量包，设置生命周期                 |
| OCR         | 确认资源包阶梯、错误码收费、QPS 默认限制和 QPS 叠加包        |
| AI          | 确认混元/TokenHub 模型路由和 token 单价，决定是否保留 OpenAI |
| CLS         | 按日志保存期确认写入、索引、存储成本                         |
| CDN/EdgeOne | 确认中国大陆流量包、HTTPS 请求费用、回源策略                 |
| 短信/邮件   | 确认 OTP、找回密码、通知的模板和套餐包                       |
| 支付        | 确认聚合支付费率、退款费、对账文件费、发票成本               |
