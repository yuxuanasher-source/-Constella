# 不同用户规模成本与利润测算模型

日期：2026-06-05

## 口径说明

本文件是 P6 套餐 v2.1 的独立规模测算表，只计算直接资源成本后的利润。

本版不计入以下成本：

- 人力成本
- 销售成本
- 办公成本
- 财税工具成本
- 客户成功成本
- 法务成本
- 获客成本
- 坏账、退款、佣金、渠道分成

本版只计入：

1. 服务器相关成本：App/Serverless、DB/缓存、Worker/队列、监控/日志、网络/下载、存储。
2. AI 成本。
3. OCR 成本。

因此，本文件中的“利润”不是完整会计利润，而是“资源成本后利润”，更接近产品直接毛利。

## 关键判断

1. 在只计算服务器、AI、OCR 成本的口径下，不存在 75 户才盈亏平衡的问题；10 户也能显示资源成本后为正。
2. 100 户时月资源成本后利润约 13.35 万，年资源成本后利润约 160.18 万。
3. 200 户时月资源成本后利润约 26.70 万，年资源成本后利润约 320.36 万。
4. 500 户时月资源成本后利润约 66.74 万，年资源成本后利润约 800.91 万。
5. 1000 户时月资源成本后利润约 133.48 万，年资源成本后利润约 1601.81 万。
6. 这个口径适合判断套餐资源毛利是否健康，不适合判断公司整体是否赚钱。
