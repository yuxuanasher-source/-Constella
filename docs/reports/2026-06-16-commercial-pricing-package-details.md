## 4. 功能边界说明

| 能力                  | 含义                                                                               |
| --------------------- | ---------------------------------------------------------------------------------- |
| 基础结算              | 按审核通过的直播报数生成待结算池、结算批次、结算明细、主播安全账单                 |
| 复杂结算规则          | 支持更复杂的 CPT、底薪、CPA、CPS、礼物、人工调整、供应商成本、毛利测算、锁定和重开 |
| 供应商协作            | 支持合作 MCN/供应商报名、协作项目、协作归因、协作结算和合作方可见范围控制          |
| 自动审核 shadow       | 系统只做自动审核建议，不直接改变业务结果                                           |
| 自动审核生产门禁      | 在通过灰度指标后，允许小流量或正式启用自动审核结果                                 |
| API / 审计 / 企业配置 | 对外集成、审计中心、企业级配置和更严格权限治理                                     |

## 5. 单独开通模块价格

用于“客户不想升级套餐，但需要某个高阶能力”的场景。建议仅作为商业例外，不应替代高阶套餐主路径。

| 模块                 |      建议价格 |     年付建议价 | 建议开放对象               | 包含能力                                                                    | 额度边界                                                                                     |
| -------------------- | ------------: | -------------: | -------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 复杂结算规则单项目包 | 99 元/项目/月 | 990 元/项目/年 | 入门版、基础版、专业版超额 | 为单个项目启用多结算方式、规则模板、人工调整、批次锁定/重开、成本与毛利字段 | 入门版/基础版按启用项目计费；专业版含 5 个项目/月，超出后按项目计费；10 个以上建议升级经营版 |
| 供应商协作包         |     999 元/月 |     9990 元/年 | 基础版、专业版             | 协作项目、合作方报名、协作归因、合作方可见范围、协作结算入口                | 最多 5 个合作方、20 个协作项目/月；超出建议升级经营版                                        |
| 协作结算增强包       |    1199 元/月 |    11990 元/年 | 基础版、专业版             | 供应商协作包 + 2 个复杂结算项目                                             | 最多 5 个合作方、20 个协作项目/月；超出 2 个复杂结算项目后按 99 元/项目/月                   |
| 企业协作扩容包       |  1999 元/月起 |       商务报价 | 经营版、企业版             | 更多合作方、更多协作项目、专属协作字段、审计导出                            | 按合作方数量、协作项目数和 API 需求报价                                                      |

定价逻辑：

- 复杂结算规则按 99 元/项目/月计费，更适合低频项目型客户；专业版附赠 5 个复杂结算项目/月，超出后继续按 99 元/项目/月计费；当客户每月启用 10 个以上复杂结算项目时，应优先推动升级经营版。
- 供应商协作包定在 999 元/月，足够体现跨组织协作、权限隔离和协作结算的业务价值，同时让高频客户自然升级经营版。
- 协作结算增强包定在 1199 元/月，等于供应商协作包 + 2 个复杂结算项目，用于打包销售；额外复杂结算项目继续按 99 元/项目/月收费。

## 7. 推荐销售路径

| 客户情况                          | 推荐销售                                         |
| --------------------------------- | ------------------------------------------------ |
| 只是小团队试用、主播少            | 入门版或基础版                                   |
| 基础版客户偶尔有复杂结算          | 基础版 + 复杂结算规则单项目包                    |
| 专业版客户开始找外部 MCN 合作     | 专业版 + 供应商协作包；复杂结算前 5 个项目已包含 |
| 既要协作又要复杂结算              | 协作结算增强包；如果使用频繁，推动升级经营版     |
| 合作方多、项目多、需要审计/API    | 经营版或企业版，不建议只靠加购包                 |
| 企业客户要求私有化、SSO、定制字段 | 企业版商务报价                                   |

## 8. 关键商业规则

1. 主播端 OCR、主播端 AI 独立收费，不消耗经营后台套餐额度。
2. OCR 用量必须强计量，额度耗尽后进入手动上传/手动填报，不允许后台静默透支。
3. AI 可允许 5% 软超额，但必须在账单页提示并生成加购建议。
4. 企业版从 12999 元/月起，不承诺无限主播、无限 OCR、无限 AI、无限存储。
5. 销售特批必须落入结构化 quota override 或 recurring add-on，不能只写备注。
6. 单独开通供应商协作和复杂结算规则时，必须设置项目数、合作方数、有效期和续费规则。
