# 收入模型测算

日期：2026-06-16

## 1. 结论

本模型只测算收入，不计固定成本、云资源成本、销售成本、人力成本、坏账和退款。收入分为两类：

1. 套餐订阅收入：入门版、基础版、专业版、经营版、企业版。
2. 主播端用量收入：主播端 OCR、主播端 AI、存储包、活跃主播席位等加购。

基准情景为：入门 40 户、基础 60 户、专业 25 户、经营 8 户、企业 2 户，共 135 户。

| 指标                      |      基准结果 |
| ------------------------- | ------------: |
| 月订阅收入，含税          |  171865.00 元 |
| 月主播端用量收入，含税    |   31322.84 元 |
| 月总收入，含税 MRR        |  203187.84 元 |
| 月总收入，不含税          |  191686.64 元 |
| 年化收入，含税 ARR        | 2438254.08 元 |
| 平均每户月收入 ARPU，含税 |    1505.10 元 |
| 主播端用量收入占比        |         15.4% |

关键判断：

- 当前收入结构以订阅为主，用量收入为辅；基准情景下用量收入约占 15%。
- 专业版和经营版是收入主力，基准情景下两档合计贡献约 57.8% 的月总收入。
- 企业版虽然只有 2 户，但贡献约 16.0% 的月总收入，因此企业版折扣和额度承诺必须严格管控。

## 10. 收入策略建议

1. 不要把主播端 OCR/AI 包进基础套餐无限使用；这部分应保持独立用量收入。
2. 专业版和经营版是主力收入档，应作为销售主推，而不是只推低价基础版。
3. 企业版必须使用结构化额度和加购合同，不写“无限量”承诺。
4. 年付 9 折适合换现金流，但会降低月等效收入；不要对所有客户默认打折。
5. 用量收入要在账单页透明展示：本月消耗、套餐额度、加购额度、预计超额和加购建议。
6. 每月复盘至少看四个指标：MRR、ARR、ARPU、用量收入占比。
