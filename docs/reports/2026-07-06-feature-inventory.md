# 产品功能全景盘点:基础 / 增值 / 核心竞争

日期:2026-07-06
方法:产品功能文档(M0–M11 + X1)+ 全代码库交叉盘点(features/ 30 个功能域、app/api/ 37 个路由域、2026-07 新增 PRD 落地核对)。
分层标准:**基础功能** = 行业 table stakes,没有就不成产品,竞品都有;**增值功能** = 拉开档位差距、支撑加购的效率放大器;**核心竞争功能** = 竞品短期抄不走的护城河,是定价的底气。

## 一、基础功能(free/basic 档就该有,卖"能用")

### 组织与协同底座
| 功能 | 说明 |
|---|---|
| 组织与权限(M0) | 五角色 RBAC(owner/运营负责人/一线运营/财务/主播),子账号创建、角色变更需原因留痕;三层权限边界(数据库 RLS + 服务层 RBAC + 前端门控) |
| 项目管理(M1) | 项目草稿→发布→招募→执行→结束全状态机;基础信息、默认结算规则、强制录屏/强制系统计时开关 |
| 主播池(M2) | 主播档案、平台账号、品类/风格标签、风险状态与黑名单(黑名单不可邀约)、近 90 天贡献统计 |
| 选播准入基础流(M3) | 主播自助报名 / 运营定向邀约 → 录屏提交 → 人工审核(通过/驳回/需修改)→ 双人最终入项确认 + 结算规则快照冻结 |
| 排班直播(M4) | 单个/批量排班、取消;开播/下播系统计时;主播只能操作自己的任务 |
| 报数提交与人工审核(M5) | 三轨时长录入(系统计时/截图时长/主播填报)、截图上传带 hash、审核通过入结算池 |
| 通知待办(M9) | 全链路事件通知(报名/待审/排班/报数/结算/异常),未读→已读→已处理状态流转 |
| 角色化看板 | owner/运营负责人/一线运营/财务四套首页:各看各的 KPI、队列和风险区,服务端 DTO 脱敏 |
| 审计日志(M7 基础面) | 全写动作留痕、高风险动作强制原因、append-only(数据库触发器禁改删) |

### 主播端与日常运营
| 功能 | 说明 |
|---|---|
| 主播移动端 + 桌面端 | 今日任务、开播下播、报数、录屏提交、审核状态、安全收益视图(只见自己的钱) |
| 主播生命周期管理 | 招募→试播→培训→转正→暂停→淘汰状态机;S/A/B/C 评级、运营分层、合同信息 |
| 考勤 / 考核 / 换班 | 按开播任务自动生成考勤 + 手工补录;考核建单与结论;换班申请-审批流 |
| 异常扫描 | 5 类履约异常自动检出(该播未播/未报数/报数逾期/缺下播截图/连播超 48h),去重推送 |
| 项目公告与报名卡 | 主播端可报名项目卡(卖点/游戏下载/强制录屏标记)+ 结构化驳回理由回流 |
| 录屏资产库 | 录屏统一存储(私有文件/B 站/外链三来源)、签名 URL 播放、按主播归档 |
| 账号库 | 平台账号集中管理(自孵化/合作/主播自有):状态生命周期、指标、登录设备与安全留痕 |

**这一层的定位**:免费/低价档给全,目的是让 MCN 把"项目-主播-排班-报数"的日常搬进来——数据进来了,增值层和竞争层才有原料。

## 三、核心竞争功能(护城河,卖"别家做不到")

### 1. 录屏 AI 解析流水线 ⭐ 你按条卖的就是它
私有录屏 → ffmpeg 抽音频 → 豆包 ASR 转写 → DeepSeek 生成六维评分卡(节奏/话术/互动/画质/合规/项目匹配)+ 分段摘要 + 风险标记 + 改进建议。全链路降级设计(任一环节挂了回退确定性草稿,任务永不卡死),成本入台账可核算。**这是 599/1099/1599 套餐表的计量主体。**

### 2. 录屏确定性智能分析 + 组织自学习校准闭环
四类零 token 成本的确定性分析:质量结构化(有效开播/挂机/露脸占比)、话术转化分类(对标高 ROI 基线给差距)、违规实时检测(高危即时通知运营)、主播能力四维评分(S/A/B/C 级)。**关键在自学习**:每日 runner 读全组织履约数据算漏斗、定位卡点、迭代评分权重和话术基线,校准版本递增可审计——**系统越用越懂这家 MCN,这是迁移成本的来源**。

### 3. 准入审核的"卡点体系 + 学习闭环"
把审核从整体拍板升级为结构化卡点评估(硬卡点/软卡点/加分点);AI 预审逐卡点给判定+置信度+转写证据;每次人工决定自动变成对齐信号(AI vs 人工、一审 vs 二审);few-shot 判例注入让模型学组织审核口味;校准达标后开快速通道(仍人工点通过,只改排序);入项 30/60 天后回看直播表现,事后校验准入决定对错。**审核数据飞轮,竞品有 AI 也没有这套闭环。**

### 4. 三轨证据链 + 结算安全模型
系统计时/截图时长/主播填报三轨互证 → 证据等级(green/yellow/red)冻结快照 → **只有强证据(green+system)自动算钱,弱证据一律人工承载**。配合结算池防漏结防重结、批次锁定重开留痕。这是对"报数可信度"这个行业痛点的结构性解法,直接决定 MCN 敢不敢把钱算在系统里。

### 5. 游戏直播垂直成本口径
CPA/CPS/礼物/投流/补播扣罚/游戏资产(CDK/账号/道具)这套口径是游戏直播行业特有的,通用直播 SaaS 没有;规则模板 + 版本化 + 导入确认 + 毛利复盘的完整闭环,让"这个项目到底赚不赚钱"第一次可算。

### 6. 全链路治理与 AI 边界(B 端信任卖点)
三层隔离(RLS + 服务层 RBAC + DTO 脱敏)、审计 append-only、高风险动作原因必填 + 预检提示;AI 安全采用成建制的 **L1–L4 工具分层**:L1 只读感知、L2 草稿需人工确认(结算/复盘草稿进 pending 队列)、L3 仅可逆低风险状态推进且经受限网关裁决、**L4 不可逆动作永不注册给 AI**——即使 AI 失控也碰不到不可逆按钮;所有建议 `requiresHumanApproval`,含数字的结论必须能溯源到 fact source。对大客户和厂家讲安全时,这一整套是差异化卖点。

### 7. AI 经营飞轮(数据复利)
履约/结算数据 → 复盘报告 → 知识库沉淀 → 作战台报价与匹配 → 星耀归因诊断 → 下一轮立项决策。单个功能竞品可以抄,**"数据在同一条链路里循环增值"抄不走**——客户用得越久,报价越准、匹配越准、审核越快。

## 四、和定价体系的对齐建议

现在有**两套分层并存**:代码里的权益档(free/basic/pro/enterprise + 5 项加购)和你套餐表的解析量档(599/1099/1599)。建议合成一张表:

| 你的档位 | 建议映射权益档 | 计量维度 | 竞争层功能 |
|---|---|---|---|
| 599 | basic(项目+结算) | 100 存 / 100 解析 | 解析流水线 ✅,自学习/准入闭环 ❌ |
| 1099 | pro(+复杂成本/导出/作战台/AI 诊断/shadow) | 300 存 / 250 解析 | 全部竞争层功能 ✅ |
| 1599 | pro 满配 + 部分 enterprise 加购 | 800 存 / 600 解析 | + 快速通道、供应商门户可选 |
| 定制 | enterprise(active 自动审核/私有化) | 面议 | 全开 |

四个执行注意:
1. **核心竞争功能大多不按量计费**(自学习校准、准入闭环、证据链是"留存钩子"不是"计量项")——把它们放进 1099+ 档位说明里,是升档理由而不是成本项;
2. **AI 功能的边际成本远比看上去低**:全仓奉行"数字确定性、叙事才用 LLM"——真正端到端调用大模型的只有星耀对话和主播诊断,其余"智能"(归因/风险雷达/匹配/定价/预审/情报)全是零 token 的确定性引擎,LLM 只做可降级的叙事改写。**真正烧钱的只有录屏解析的 ASR**,这正是把它单独做成计量项收费的原因,其余 AI 能力可以放心作为档位权益赠送;
3. 审计已发现的口径问题在这里同样适用:解析配额还没在代码里强制(F3)、"条"要绑定 15 分钟时长上限,否则档位成本模型失真;
4. 权益墙强度不一:只有 project_management/settlement/complex_cost_rules 是路由级硬门禁,作战台/导出/AI 诊断靠前端付费墙 + 角色兜底——正式收费前建议把付费墙下沉到路由层,否则懂技术的客户可以绕过前端直接调 API。
