# 经营舱手动验收测试用例

本文根据 `C:\Users\admin\Desktop\经营舱-产品设计文档.md` 编写，用于第一版经营舱的人工验收。覆盖 P0-P4：账号权限、项目与主播准入、排班直播、报数审核、结算、审计、导出、通知、智能作战台基础能力。P5 SaaS 商业化作为后续预留验收项。

## 执行原则

- 所有用例均以同一组织内数据为主，同时准备一个跨组织数据用于越权验证。
- 涉及敏感字段的用例必须同时检查页面显示和接口返回，不能只看前端是否隐藏。
- 高风险操作必须同时验证三件事：原因必填、审计日志有改前改后、负责人收到提醒。
- 结算相关用例必须区分“系统核验金额”和“人工录入/主张值”，不能混在一个金额口径里验收。
- 每条用例执行后记录结果：`通过 / 不通过 / 阻塞 / 不适用`，并附截图、接口响应或日志 ID。
