# 单页面迁移提示词模板

将尖括号内容替换后使用，一次只迁移一个页面或紧密关联的一组页面。

```text
迁移经营舱页面：<页面名称>

视觉源：public/arco-redesign/<原型文件>.html
正式路由：<正式路由>
现有业务域：<features 目录>
现有 API：<app/api 目录>

任务目标：
1. 像素级实现对应原型的页面布局、文本层级、控件状态和响应式行为。
2. 复用现有鉴权、feature service、DTO 和 API，不改变业务合同。
3. 将旧 ops-reference.jsx 中属于本页面的显示转换和动作按 model/server/client/ui 边界迁入所属业务域。
4. 路由 page 负责服务端鉴权、首屏查询和组合；交互拆成最小 Client Component。
5. 筛选、分页、排序和标签页进入 URL Search Params。
6. 保留功能开关和旧页面回滚入口。

禁止：
- 不使用模拟数据替代真实接口。
- 不把整页声明为 Client Component，除非能证明所有区域都需要客户端能力。
- 不新增全局 Provider 或全局 store。
- 不复制完整原型 CSS 到页面组件。
- 不在同一改动中重写 API、数据库或权限模型。
- 不删除尚未迁移页面使用的旧逻辑。

状态要求：
- 默认、加载、空数据、无匹配结果、API 错误、无权限、操作中和操作成功。
- 主要弹窗/抽屉、表格选中、禁用、高风险确认状态。
- 高风险动作必须显示影响范围并保留服务端权限校验。

性能要求：
- 服务端输出首屏主要内容。
- 单页面新增客户端 JS <= 100KB gzip。
- 搜索约 250ms 防抖并取消过期请求。
- 列表默认服务端分页，每页 30-50 条。
- 页面隐藏时暂停本页面轮询。

测试与验收：
- 为 ViewModel/DTO adapter 添加单元测试。
- 为主要交互添加 Testing Library 测试。
- 为桌面、紧凑桌面和移动端建立 Playwright 截图。
- 几何误差 <= ±1px，首轮截图差异 <= 0.2%。
- 运行 lint、type-check、API contract、相关业务测试、UI smoke 和 build。

完成报告必须包含：
- 文件和路由变化。
- 复用的现有服务/API。
- 新旧行为差异。
- 截图和性能结果。
- 未覆盖状态与剩余风险。
```
