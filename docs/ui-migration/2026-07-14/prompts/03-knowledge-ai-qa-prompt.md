# 知识库、AI 与最终 QA 提示词

```text
迁移经营舱知识库和星耀 AI 作战台，并完成全站视觉与性能收口。

视觉源：
- public/arco-redesign/knowledge-base.html
- public/arco-redesign/ai-workbench.html
- public/arco-redesign/constella-ui.html

正式路由：
- /console/knowledge
- /console/ai

复用：
- features/ai
- features/war-room
- app/api/knowledge-base
- app/api/ai/**
- 项目现有 Markdown 安全渲染工具

知识库要求：
1. 实现分类、搜索、文档列表、文档阅读和详情选中状态。
2. 编辑按钮进入真正的 Markdown 文档内容编辑，不是只编辑摘要。
3. 编辑体验接近在线文档：标题、正文、Markdown 工具栏、预览、保存状态、未保存提醒和版本信息。
4. 编辑器动态导入；阅读页面不要加载完整编辑器代码。
5. 输出 HTML 必须经过项目已有安全净化，禁止使用原型中的 CDN。
6. 保留 AI 引用状态、权限范围和审计信息。

AI 作战台要求：
1. 页面主体铺满可用区域，不保留多余页面标题带。
2. 左、中、右三列顶部高度统一；中间对话区自适应剩余高度。
3. 支持开始新对话、历史对话、智能体切换、消息、附件、上下文和生成产物。
4. 对话结果必须展示来源、置信信息和需要人工确认的边界。
5. 任务上下文面板允许按视口隐藏或折叠，隐藏后主对话区铺满。
6. AI、附件和编辑器相关重模块按需加载，不进入公共壳层 chunk。

最终 QA：
- 为 12 个正式路由建立 Playwright 截图矩阵。
- 覆盖 1920x1080、1440x900、1280x800、768x1024、390x844。
- 检查普通文本字号统一、侧栏尺寸、顶栏高度、表格对齐、弹窗边界和移动端溢出。
- 冻结截图中的日期、轮询、动画和随机数据。
- 输出逐路由客户端 JS、LCP、INP、CLS 和截图差异报告。
- 运行 lint、type-check、全部测试和生产构建。

发布：
- 使用功能开关或组织白名单进行内部、10%、50%、100% 灰度。
- 保留旧 UI 一个发布周期。
- 监控客户端错误、API 失败、路由加载时间和高风险动作成功率。
- 仅在所有门禁通过后删除 ops-reference.jsx 中已经失去引用的页面视图。
```
