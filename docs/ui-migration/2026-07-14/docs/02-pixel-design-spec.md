# 像素级视觉规格

## 1. 视觉源

- 可编辑源稿：`frontend-design/source/*.html` 与共享 CSS。
- 整体评审稿：`frontend-design/single-file/constella-ui.html`。
- 正式实现必须以对应独立页面为细节基准，以单文件版本验证跨页面导航一致性。

## 2. 固定尺寸

| 项目 | 桌面 | 中等宽度 | 移动端 |
|---|---:|---:|---:|
| 侧栏宽度 | 248px | 220px（901-1024） | 转为顶部横向导航（<=900） |
| 顶栏高度 | 68px | 68px | 60px |
| 导航项高度 | 38px | 38px | 38px |
| 导航数字徽标 | 20px | 20px | 20px |
| 卡片圆角 | 6px | 6px | 6px |
| 普通控件圆角 | 4-6px | 4-6px | 4-6px |

## 3. 字体层级

| 用途 | 字号 | 字重 |
|---|---:|---:|
| 普通文本、表格、表单 | 12px | 400/500 |
| 分区标题 | 14px | 600 |
| 品牌名称 | 16px | 600/700 |
| 页面主标题 | 22px | 600/700 |
| 关键指标 | 28-36px | 600/700 |

除页面主标题、品牌、分区标题和关键指标外，不允许页面自行放大普通文字。字间距保持 `0`，不得用负字间距压缩中文。

## 4. 基础颜色

以下值以源稿 CSS 为最终依据，正式实现通过 token 引用：

```css
--ops-bg: #f7f8fa;
--ops-surface: #ffffff;
--ops-border: #e5e6eb;
--ops-text-1: #1d2129;
--ops-text-2: #4e5969;
--ops-text-3: #86909c;
--ops-primary: #165dff;
--ops-success: #00b42a;
--ops-warning: #ff7d00;
--ops-danger: #f53f3f;
```

## 5. 布局和状态

- 页面主要区域不使用装饰性浮动卡片；卡片只用于独立数据项、工具和弹窗。
- 页面级分栏必须使用明确的 Grid/Flex 轨道，不依靠空白 margin 撑开。
- 表格行、筛选栏和工具栏高度必须稳定，加载和徽标变化不得引发布局跳动。
- 所有页面具备默认、加载、空数据、错误、无权限和操作中状态。
- 表格和列表必须有选中、悬停、键盘焦点及禁用状态。
- 删除、锁定、结算、导出等高风险动作必须有确认和结果反馈。

## 6. 响应式验收视口

- 1920 x 1080
- 1440 x 900
- 1280 x 800
- 1024 x 768
- 768 x 1024
- 390 x 844

所有视口不得出现正文被侧栏覆盖、按钮文字溢出、表头错位、弹窗超出屏幕或无意的双滚动条。

## 7. 像素验收

- 壳层和固定控件几何误差不超过 `±1px`。
- 普通组件尺寸误差不超过 `±2px`。
- 使用同一 Chromium、字体和操作系统生成截图基线。
- 首轮 `maxDiffPixelRatio <= 0.002`，稳定后收紧至 `0.001`。
- 动画、时间、随机数据和轮询在截图模式中冻结。
- 对默认、空态、错误态、弹窗、抽屉、选中行和编辑态分别建立基线。

## 8. 可访问性

- 图标按钮必须有 `aria-label` 和可见焦点。
- 标签页、菜单、对话框使用正确语义和键盘行为。
- 文本颜色满足 WCAG AA 对比度。
- 不只依靠颜色表达风险或状态。
- 支持 `prefers-reduced-motion`。
